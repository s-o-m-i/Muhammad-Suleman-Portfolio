# Muhammad Suleman — Portfolio

Professional portfolio for Muhammad Suleman, Full-Stack Developer & SEO Specialist.

## Stack

- Next.js (App Router) and TypeScript
- Tailwind CSS
- Motion
- Lucide React

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Update personal details, projects, and experience in `src/data/`.

Add a LinkedIn URL in `src/data/site.ts` when confirmed.
The resume page at `/resume` can be printed to PDF.
